Dataset

Kaggle “Air Quality Data in India (2015–2020)”, Jaipur rows only (originally from CPCB). Daily city averages. All figures below come from the saved training run.

Outliers were flagged with the 1.5 × IQR rule but kept, because extreme pollution days are real events. Missing values were forward-filled for at most 3 consecutive days.

About the project

Method

The target is AQI on day t; every predictor comes from day t-1, so no future information leaks in. The data is split in time order (first 80% train, last 20% test). Models are compared on the test set using R², MAE and RMSE, against a baseline that simply repeats today’s AQI. The best model is the one with the lowest test RMSE.

Limitations

Data ends on 2020-07-01, so this is a historical study, not live air quality, and not an official forecast. Daily city averages hide hourly and station detail. Only previous-day values are used, with no weather data. The polynomial terms can over-fit or extrapolate badly outside the training range, so very unusual inputs deserve caution.

AQI categories follow the CPCB bands: Good 0–50, Satisfactory 51–100, Moderate 101–200, Poor 201–300, Very Poor 301–400, Severe 401+.
